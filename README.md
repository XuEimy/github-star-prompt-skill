# GitHub Star Prompt Skill

An agent skill for adding an optional, dismissible GitHub star prompt to an application. It covers timing, persistence, explicit user action, and failure handling without prescribing a particular framework.

## Install

Copy `skills/github-star-prompt` into your agent's skills directory, for example `~/.codex/skills/github-star-prompt`. Then ask your agent to use `github-star-prompt` when adding the feature.
